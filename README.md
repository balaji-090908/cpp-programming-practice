# C++ Programming Practice

A personal learning repository documenting my journey with C++ programming, problem-solving, and data structures and algorithms.

| Folder | Contents |
|---|---|
| `01-Basics` | First programs, variables, input/output, conditions, and loops |
| `02-Arrays` | Array fundamentals and practice |
| `03-Strings` | String operations and practice |
| `04-Mathematics` | Number-based problems and mathematical logic |
| `05-Functions` | Function basics and examples |
| `06-DSA` | Data structures and algorithms |
| `07-LeetCode` | My LeetCode solutions, added as I solve them |

## How to Compile and Run

Using g++:

```bash
g++ filename.cpp -o program
./program
```

On Windows:

```bash
g++ filename.cpp -o program.exe
program.exe
```
