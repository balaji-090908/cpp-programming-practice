## ▶️ How to Run the Programs

You can run the C++ programs on your local machine using a C++ compiler.

**Step 1: Clone this repository**

```bash
git clone https://github.com/balaji-090908/cpp-programming-practice.git
```

**Step 2: Navigate into the repository**

```bash
cd cpp-programming-practice
```

**Step 3: Compile a C++ program**

```bash
g++ 01-Basics/hello-world.cpp -o hello
```

**Step 4: Execute the program**

Windows:

```bash
hello.exe
```

Linux / macOS:

```bash
./hello
```
